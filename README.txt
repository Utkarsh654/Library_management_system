LIBRARY MANAGEMENT SYSTEM - FLASK + SQLITE

1. Open this folder in VS Code.
2. Open Terminal.
3. Create virtual environment:
   python -m venv venv
4. Activate:
   venv\Scripts\activate
5. Install:
   python -m pip install -r requirements.txt
6. Run:
   python app.py
7. Open:
   http://127.0.0.1:5000
